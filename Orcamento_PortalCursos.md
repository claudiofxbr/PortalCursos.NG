## 1. Escopo do Projeto
Desenvolvimento e implantação do sistema web "PortalCursos.NG". O sistema será composto por 7 (sete) módulos principais, cobrindo as necessidades de gestão acadêmica, administrativa e de controle de usuários.

## 2. Tecnologias Utilizadas
O projeto será desenvolvido com arquitetura moderna e escalável, utilizando as seguintes tecnologias:
- **Frontend / Interface:** HTML5, CSS3, e JavaScript.
- **Framework Frontend:** Next.js (tecnologia de ponta em React para alta performance e SEO).
- **Backend / Regras de Negócio:** Java (Spring Boot) para alta segurança e processamento robusto.
- **Banco de Dados:** Banco de dados relacional hospedado na nuvem **Neon** (PostgreSQL serverless).
- **Segurança da Informação:** Sistema de autenticação de múltiplas camadas (frontend e backend), senhas criptografadas (BCrypt/Argon2) e proteção JWT, além de comunicação segura via HTTPS/SSL.
